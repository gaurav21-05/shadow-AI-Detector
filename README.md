# 🕵️ Shadow AI Detector

Shadow AI Detector is an intelligent web application designed to identify and analyze AI-generated content. It helps users evaluate text authenticity by detecting patterns commonly associated with AI-written content and providing detailed insights.

## 🚀 Features

- 🤖 AI-generated content detection
- 📊 Confidence score and analysis
- ⚡ Fast and responsive interface
- 📱 Mobile-friendly design
- 🔍 Real-time text evaluation
- 🎨 Clean and intuitive UI

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- API Integration

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/shadow-ai-detector.git
```

### Navigate to Project

```bash
cd shadow-ai-detector
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will run at:

```bash
http://localhost:3000
```

## 🌐 Environment Variables

Create a `.env.local` file in the root directory.

```env
NEXT_PUBLIC_API_URL=your_api_url
API_KEY=your_api_key
```

## 🎯 Usage

1. Open the application.
2. Paste or type the text you want to analyze.
3. Click **Analyze**.
4. View the AI detection results and confidence score.
